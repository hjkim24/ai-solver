Clipboard AI Solver — 설치 및 첫 실행

지원 환경
- macOS 13 이상이 필요합니다. 내려받은 파일 이름의 아키텍처를 확인하세요.
- arm64는 Apple Silicon(M 시리즈), x86_64는 Intel Mac용입니다.
  두 이름이 함께 표시된 파일만 양쪽에서 사용할 수 있습니다.
- 인터넷 연결과 사용자 본인의 OpenAI 또는 Anthropic API 키가 필요합니다. API 사용료는 별도입니다.

설치
1. DMG를 열고 Clipboard AI Solver.app을 Applications 폴더로 드래그합니다.
2. 응용 프로그램 폴더에서 Clipboard AI Solver를 실행합니다.
3. 확인되지 않은 개발자 또는 공증되지 않은 앱이라는 이유로 실행이 차단되면,
   시스템 설정 → 개인정보 보호 및 보안 → 보안 → '그래도 열기'를 선택합니다.
4. macOS의 추가 확인과 인증을 완료한 뒤 앱을 엽니다.
   이 버튼은 앱 실행을 시도한 뒤 약 1시간 동안 표시됩니다.
   관리되는 회사·학교 Mac은 관리자 정책 때문에 허용이 불가능할 수 있습니다.

Apple 안내: https://support.apple.com/ko-kr/102445
이 배포본은 Apple Developer ID 서명·공증을 받지 않았습니다.
신뢰하는 배포처의 파일인지 확인하세요. 악성코드 탐지나 손상 경고는 별도로 점검해야 합니다.

사용
1. 메뉴 바 '—' → 설정 → AI 연결에서 공급자를 고르고 본인의 API 키를 입력합니다.
   '모델 불러오기'를 누르고 목록에서 모델을 선택해 저장합니다.
   풀이 모드는 설정 → 일반에서 선택합니다.
2. 메뉴에서 '사용 시작'을 누릅니다. 실행할 때마다 중지 상태로 시작합니다.
3. 문제 하나와 모든 보기가 보이도록 준비한 뒤 Control–Shift–Command–3으로
   전체 화면을 클립보드에 복사합니다. 영역 복사는 Control–Shift–Command–4입니다.
4. 메뉴에 표시되는 숫자는 위에서부터 1로 세는 보기 위치입니다.
   '최근 결과'에서 인식한 문항과 해설을 확인하세요.
5. '사용 중지'를 누르면 이미지 감시와 진행 중인 풀이를 중단합니다.

감시 중 새로 복사한 모든 이미지가 선택한 AI 공급자로 전송됩니다.
전체 화면의 개인정보를 정리한 뒤 캡처하세요. 답변은 AI가 잘못 판단할 수 있습니다.
배포 파일에는 개발자의 API 키·자료 목록·개인 설정이 포함되지 않습니다.
OpenAI 자료는 본인 OpenAI 계정에 업로드됩니다. Claude 자료는 Mac에 사본을 저장하고
첨부자료 우선 AI에서 선택한 원본을 풀이할 때 Anthropic으로 전송합니다. 자료는 공급자별로
관리하며 자동 이동하지 않습니다. 자료 관리에서 해당 사본·원격 자료를 제거할 수 있습니다.
Claude 첨부 합계는 12 MB 이하입니다.

Caps Lock LED
- MacBook 내장 키보드 전용입니다. 다른 Mac에서 물리 LED 동작은 별도 확인이 필요합니다.
- 설정 → 알림에서 켜고 'LED 3회 테스트'로 확인하세요.
- 입력 모니터링을 요청하면 Clipboard AI Solver에 허용한 뒤 앱을 종료·재실행합니다.
- 0.2.1의 고정 자체 서명으로 전환하는 최초 한 번은 기존 입력 모니터링 항목을
  제거하고 새 앱을 다시 추가해야 할 수 있습니다. 이후 업데이트는 같은 인증서로 서명합니다.
- 인증서·bundle ID 변경, OS 보안 정책 변경 등에는 권한 재허용이 필요할 수 있습니다.

업데이트
실행 중인 앱을 메뉴에서 정상 종료한 뒤 새 앱으로 교체하세요.
키와 설정은 각 사용자 Mac에 저장되며 DMG를 다시 받아도 배포자에게 전송되지 않습니다.
