# Clipboard AI Solver

브라우저 확장 없이 실행되는 별도 macOS 메뉴 앱. 기존 Canvas RAG Solver와 기존 빌드·확장·설정·키는 유지한다.

## 사용자 흐름

1. 새 앱 실행 → 📋 메뉴 → 설정에서 새 API 키 저장. 기본 모드는 일반 AI, LED는 꺼짐.
2. 사용 시작 → 문제 하나와 모든 보기가 보이도록 화면 준비 → Control–Shift–Command–3으로 클립보드에 전체 화면 복사.
3. 새 이미지 한 개만 처리. 텍스트·파일 복사, 사용 시작 전의 이미지는 무시한다. 새 이미지는 이전 작업과 LED 점멸을 취소한다.
4. 이미지 정규화 → AI 문항 인식 → 일반 AI / 첨부자료 우선 AI / 엄격한 RAG 풀이 → 메뉴에 1부터 시작하는 보기 위치 표시. 최근 결과에서 인식 내용·근거·토큰 확인.
5. LED를 켰다면 정답 번호만큼 점멸한다. 사용 중지·종료 시 작업 취소와 LED 원복.

## 경계

- 이름 Clipboard AI Solver, bundle ID와 Keychain service는 com.hjkim24.clipboard-ai-solver. 기존 키와 자료 목록을 자동 이전하지 않는다.
- 실행할 때마다 감시 중지 상태. 감시 중 새로 복사한 모든 이미지가 처리 대상이며 전체 화면은 OpenAI로 전송된다. 화면의 개인정보는 사용자가 정리한다.
- 입력 64 MiB 이하, 단일 이미지, 최대 40 MP/한 변 20,000 px. 메타데이터를 제거한 PNG 10 MiB 이하. 애니메이션·다중 이미지·불명확한 문항은 보류.
- AI가 여러 문제·복수 정답·잘린 보기를 감지하면 보류. 인식 오류를 완전히 검출할 수는 없다. 단일 정답 객관식 2~10개 보기만 지원한다.
- 인식과 풀이에 Responses API를 각각 호출하며 45초 전체 제한. RAG는 준비된 자료가 없으면 유료 호출 전에 보류. 실패 자동 재시도 없음.
- 자료 업로드·모드·인용 검증·LED 드라이버는 기존 구현을 재사용한다. 원본 첨부 인용은 파일 ID만 검증하며 원문 대조는 사용자 확인이 필요하다.
- 앱 전용 캡처·OCR·전역 단축키·브라우저 DOM 접근·로그인·답안 제출·파일 감시는 범위 밖이다.

## 검증

별도 pasteboard와 합성 이미지, 모의 API로 검증한다. 실제 클립보드·Keychain·유료 API는 개발 테스트에서 읽거나 사용하지 않는다. 임시 번들로 직접 실행/정상 종료를 확인한다. 기존 37개 파일의 SHA-256이 작업 전과 동일한지 확인한다. 실제 스크린샷 인식 정확도와 물리 LED는 사용자 확인이 남는다.
