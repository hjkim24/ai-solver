# 풀이 모드 추가

기존 RAG 계약은 RAG 모드에 유지한다. 사용자는 설정에서 다음 모드를 고른다.

| 모드 | 입력 | 자료가 부족할 때 |
| --- | --- | --- |
| 일반 AI | 문항 이미지·텍스트 | 모델 지식으로 판단, 불확실하면 보류 |
| 첨부자료 우선 AI | 문항 + 자료 관리에서 체크한 원본 파일 | 모델 지식으로 판단하며 결과에 구분 표시 |
| RAG | 문항 + 준비된 자료의 검색 구절 | 근거 없으면 보류 |

- 기존 설치의 기본값은 RAG로 유지한다. 이전 모델·파일·저장소 설정을 보존한다.
- 첨부 모드는 Responses의 `input_file`에 업로드한 file_id를 전달한다. 기존 파일은 선택하지 않은 상태로 이행하고 새로 추가하는 파일은 선택한다. 선택 파일이 없으면 일반 AI처럼 동작한다.
- PDF/TXT/MD를 지원한다. 첨부는 파일당 50 MB 미만, 합계 50 MB 이하로 제한한다. 기존 파일의 크기가 없으면 Files 메타데이터를 조회한다. 초과·파일 조회·API 오류를 일반 AI 성공으로 바꾸지 않는다.
- 기존 자료 등록과 원격 삭제 흐름을 재사용하므로 등록 파일은 RAG 인덱싱도 수행한다. 첨부 모드는 인덱싱 완료를 기다리지 않는다.
- 답의 근거를 자료 / AI 지식 / 혼합 / 없음으로 표시한다. RAG 인용은 검색 구절과 대조한다. 원본 첨부 인용은 파일 ID만 검증 가능하므로 원문 확인 필요를 표시한다.
- 모드·선택 파일 변경은 진행 중 작업과 이전 답을 무효화한다. 일반 AI는 자료 인덱싱 상태 변화의 영향을 받지 않는다.
- 외부 도구·웹 검색·자동 제출은 추가하지 않는다. 모델 지식은 정답을 보장하지 않는다.

근거: [OpenAI File inputs](https://developers.openai.com/api/docs/guides/file-inputs), 2026-10-20 확인. PDF는 텍스트와 페이지 이미지, 비 PDF는 추출 텍스트를 입력한다. 직접 첨부는 매 요청 입력 비용이 커질 수 있다.
