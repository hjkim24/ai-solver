# App icon and normal Mac installation

Goal: 앱 컨셉에 맞는 아이콘을 만들고 현재 Mac의 /Applications 설치와 새 배포본에 적용한다. 기능과 개인 데이터는 유지한다.

Design: imagegen으로 생성한 청록색 타일, 흰 문서와 객관식 선택 표시. 투명한 외곽을 포함한 기존 macOS .icns용 단일 이미지. 메뉴 바는 기존 숫자/상태 표시 그대로.

Scope: AppIcon PNG/prompt/icns, 재생성 스크립트, Info.plist의 아이콘/버전 0.1.1, build resource copy, 정상 종료→검증된 임시 사본→/Applications 교체→실행 설치 경로, 문서/DMG. 공유 Swift·API·클립보드·LED·Keychain 코드는 변경하지 않는다. 기존 0.1.0 배포 파일은 보존한다. .git 메타데이터는 수정하지 않는다.

Verification: 아이콘 16~1024 크기/알파/ICNS 확인, 격리 임시 디렉터리에서 설치·다른 앱 보호·교체 실패 원복 검사, 새 번들 직접 실행/종료 및 아이콘 해석, 최종 /Applications 프로세스 확인, DMG 구성·서명·해시 검증, 모든 Swift 원본 해시 대조. 실제 API 키/일반 클립보드/유료 API/물리 LED는 테스트하지 않는다.

Release: dist/Clipboard-AI-Solver-0.1.1-arm64.dmg 및 .sha256. 기존 0.1.0 배포본 보존. 실제 유료 API 호출·물리 LED는 재검사하지 않았다. ad hoc 서명 갱신으로 macOS 권한을 다시 허용해야 할 수 있다.
