# Clipboard AI Solver v0.2.3

스크린샷 속 객관식 문항을 OpenAI 또는 Claude로 읽고 풀이하는 macOS 메뉴 바 앱입니다.

## 다운로드

- [Apple Silicon용 DMG](https://github.com/hjkim24/ai-solver/releases/download/v0.2.3/Clipboard-AI-Solver-0.2.3-arm64.dmg)
- [SHA-256 체크섬](https://github.com/hjkim24/ai-solver/releases/download/v0.2.3/Clipboard-AI-Solver-0.2.3-arm64.dmg.sha256)

Apple Silicon · macOS 13 이상을 지원합니다. 본인의 OpenAI 또는 Anthropic API 키가 필요하며 API 사용료는 별도입니다.

## 풀이 모드와 자료

- **일반 AI**: 자료 없이 문항 이미지와 모델 지식으로 판단합니다.
- **첨부자료 우선 AI**: 체크한 원본 파일을 먼저 참고하고, 근거가 부족하면 모델 지식으로 보완합니다.
- PDF·UTF-8 TXT·MD를 등록하고 공급자별로 첨부할 파일을 선택합니다.
- OpenAI는 파일당 50 MB 미만·선택 합계 50 MB 이하, Claude는 파일당·선택 합계 12 MB 이하입니다.
- OpenAI 자료는 계정에 업로드하고, Claude 자료는 Mac에 사본을 보관해 첨부할 때 전송합니다.
- 저장된 API 키·모델·자료·첨부 선택·LED 설정을 유지합니다.

## 설치와 사용

DMG에서 앱을 Applications 폴더로 드래그합니다. 자체 서명 앱으로 Apple 공증을 받지 않았으며, 최초 실행이 차단되면 시스템 설정 → 개인정보 보호 및 보안 → **그래도 열기**로 허용합니다.

설정에서 공급자·API 키·모델과 풀이 모드를 저장한 뒤 **사용 시작**을 누릅니다. 문제 하나와 모든 보기를 Control–Shift–Command–3 또는 Control–Shift–Command–4로 클립보드에 복사하세요. 메뉴 바에 보기 번호가 표시되며 최근 결과에서 인식 내용·해설·출처를 확인할 수 있습니다. MacBook 내장 Caps Lock LED 알림도 지원합니다.
