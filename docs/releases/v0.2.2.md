# Clipboard AI Solver v0.2.2

브라우저 확장 없이 스크린샷 속 객관식 문항을 읽고 풀이하는 macOS 메뉴 바 앱입니다.

## 다운로드

- [Apple Silicon용 DMG](https://github.com/hjkim24/ai-solver/releases/download/v0.2.2/Clipboard-AI-Solver-0.2.2-arm64.dmg)
- [SHA-256 체크섬](https://github.com/hjkim24/ai-solver/releases/download/v0.2.2/Clipboard-AI-Solver-0.2.2-arm64.dmg.sha256)

지원 환경은 **Apple Silicon · macOS 13 이상**입니다. 본인의 OpenAI 또는 Anthropic API 키가 필요하며 API 사용료는 별도입니다. Intel Mac 배포본은 포함하지 않습니다.

## 포함 기능

- OpenAI·GPT / Anthropic·Claude 선택과 이미지·구조화 출력 지원 모델 목록 조회
- 일반 AI, 첨부자료 우선 AI, RAG 자료 근거 모드
- 클립보드 이미지 입력, 메뉴 바 답 번호, 문항 인식 내용·해설·출처 확인
- MacBook 내장 Caps Lock LED 알림과 3회 테스트
- macOS 기본 설정 화면과 라이트·다크 모드

## 업데이트 시 LED 권한 유지

0.2.1부터 동일한 로컬 코드 서명 인증서를 재사용합니다. 이 Mac에서는 0.2.1에서 0.2.2로 실제 업데이트한 뒤 입력 모니터링에 앱을 재등록하지 않고 LED 3회 점멸을 확인했습니다. 다른 Mac·OS 버전은 별도 확인 대상입니다.

## 설치와 첫 실행

1. DMG에서 앱을 Applications 폴더로 드래그합니다.
2. 최초 실행이 차단되면 시스템 설정 → 개인정보 보호 및 보안 → **그래도 열기**로 허용합니다. 이 배포본은 자체 서명이며 Apple 공증을 받지 않았습니다.
3. 메뉴 바 **— → 설정 → AI 연결**에서 공급자와 키를 입력하고 **모델 불러오기 → 선택 → 저장**을 누릅니다.
4. **사용 시작** 후 문제 하나와 모든 보기를 **Control–Shift–Command–3** 또는 **Control–Shift–Command–4**로 복사합니다.

LED를 켜면 입력 모니터링 허용이 필요할 수 있습니다. 0.2.0 및 그 이전 임시 서명 버전에서 전환할 때에는 기존 권한 항목을 한 번 제거하고 새 앱을 추가해야 할 수 있습니다.

## 검증과 한계

모의 API·네이티브 UI·서명·설치·앱 실행/종료·DMG 무결성 검사를 통과했습니다. 이전 OpenAI 일반·첨부 모드는 사용자 실제 확인을 거쳤고, 새 Claude 경로의 실제 유료 추론과 RAG 품질의 정량 평가는 별도입니다. Claude RAG는 로컬 어휘 검색을 사용하며 동의어·스캔·그림 검색에 한계가 있습니다.

사용 중 복사한 이미지는 선택한 AI 공급자로 전송됩니다. DMG에는 개인 키·설정·자료·빌드 인증서의 개인 키가 포함되지 않습니다. 자세한 동작과 제한은 [README](https://github.com/hjkim24/ai-solver#readme)를 참고하세요.
