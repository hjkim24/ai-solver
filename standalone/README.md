# Clipboard AI Solver

스크린샷 속 객관식 문항을 OpenAI 또는 Claude로 풀이하는 macOS 메뉴 바 앱입니다. **일반 AI**와 **첨부자료 우선 AI**를 지원합니다.

설치·사용법, 공급자별 첨부 제한과 개인정보 처리, 검증 상태는 [프로젝트 README](../README.md)를 참고하세요.

저장소 루트에서 실행합니다.

```bash
bash scripts/build.sh
open 'build/Clipboard AI Solver.app'
```

검사: `bash scripts/check.sh` · 설치: `bash scripts/install.sh` · DMG 생성: `bash scripts/package.sh`
